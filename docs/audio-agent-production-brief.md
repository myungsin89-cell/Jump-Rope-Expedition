# 줄넘기 원정대 오디오 제작 에이전트 지시서

이 문서는 다른 제작 에이전트에게 그대로 전달하는 작업 지시서다.  
음악 방향을 먼저 승인한 뒤 효과음을 확장하여, 분위기가 맞지 않는 오디오를 한꺼번에 만드는 일을 방지한다.

---

## 에이전트에게 전달할 지시

당신은 교실용 웹게임 **줄넘기 원정대**의 음악·효과음 제작 담당자다.

작업을 시작하기 전에 반드시 다음 문서를 읽고, 이미 확정된 게임 구조와 용어를 바꾸지 않는다.

1. `줄넘기_원정대_개발_마스터_명세서_v1.0.md`
2. `docs/decision-log.md`
3. `docs/design-system.md`
4. `assets/illustrations/title-screen-cover-v1.png`
5. `assets/illustrations/units/`
6. `assets/illustrations/bosses/`
7. `assets/illustrations/heroes/`

기존 결정이 문서에 있으면 다시 묻지 말고 따른다. 문서에 없는 결정만 사용자에게 하나씩 확인한다.

### 작업 경계

- 이번 작업은 음악·효과음 제작과 오디오 명세 정리까지다.
- 게임 규칙, 점수, 영웅 효과, 보스 능력치, 화면 구조를 변경하지 않는다.
- 앱 코드에 오디오를 연결하거나 기존 코드를 수정하지 않는다. 연결 작업을 별도로 요청받은 경우에만 한다.
- 외부 음원을 무단으로 내려받거나 저작권이 불분명한 샘플을 사용하지 않는다.
- 특정 게임·애니메이션·영화 음악을 그대로 모방하지 않는다.
- 학생용 화면에서는 `리그`, `레이드`, `리그 포인트`라는 용어를 사용하지 않는다. 전투 명칭은 `최종 대전`이다.

## 1. 게임과 음향의 방향

줄넘기 원정대는 3개 팀이 줄넘기 기록으로 병력과 영웅을 준비하고, 시즌 마지막에 같은 비밀 보스를 함께 쓰러뜨리면서 실제 피해량을 겨루는 교실용 협력·경쟁 게임이다.

### 핵심 정서

- 따뜻한 숲속 원정
- 작은 모험을 시작하는 설렘
- 친구들과 함께 준비하는 느낌
- 최종 대전에서는 긴장감이 생기지만 무섭거나 잔혹하지 않음
- 결과 발표에서는 세 팀 모두 보스를 쓰러뜨렸다는 공동 성취감을 먼저 전달

### 음악 키워드

- warm forest fantasy
- hand-crafted storybook adventure
- light acoustic percussion
- wooden mallet, pizzicato strings, soft flute, kalimba, glockenspiel을 절제해서 사용
- 자연스럽고 유기적인 질감
- 밝고 기억하기 쉬운 짧은 주제 선율
- 지나치게 유아적이거나 장난감 광고처럼 들리지 않음

### 피해야 할 방향

- 웅장함만 강조한 영화 예고편 음악
- 무겁고 어두운 전쟁 음악
- 공포스러운 괴물 소리
- 과도한 전자음, 사이렌, 날카로운 고음
- 슬롯머신·도박 게임처럼 들리는 보상음
- 수업 중 반복 재생하기 피곤한 밀도 높은 음악
- 음성 대사, 알아들을 수 있는 노래 가사, 팀 이름을 외치는 소리

## 2. 반드시 지킬 제작 순서

### 1단계 · 현재 파일 확인

- 저장소에서 기존 오디오 파일과 오디오 관련 문서를 먼저 검색한다.
- 기존 파일이 있으면 덮어쓰지 말고 목록과 상태를 보고한다.
- `assets/audio/`가 없다면 승인된 작업 단계에서만 새로 만든다.

### 2단계 · 인트로 음악 3개 시안만 제작

처음부터 전체 음악과 효과음을 만들지 않는다. 아래 세 방향으로 각각 **12~20초 길이의 인트로 음악 시안**을 먼저 만든다.

| 시안            | 방향                           | 핵심 악기와 느낌                                                                          |
| --------------- | ------------------------------ | ----------------------------------------------------------------------------------------- |
| A · 아침의 원정 | 따뜻하고 편안한 시작           | 어쿠스틱 기타 또는 우쿨렐레를 과하지 않게 사용하고, 나무 타악기와 플루트로 숲의 아침 표현 |
| B · 숲의 행진   | 팀 활동과 모험성 강조          | 가벼운 스네어·우드블록 리듬, 피치카토 현, 짧은 호른 또는 플루트 주제                      |
| C · 별빛 탐험   | 신비롭고 조금 더 게임다운 느낌 | 칼림바·글로켄슈필·부드러운 패드, 따뜻한 저음 현으로 비밀 보스의 존재 암시                 |

세 시안은 같은 음량 기준으로 비교할 수 있어야 한다. 시안마다 다음 내용을 함께 보고한다.

- 의도와 사용 악기
- BPM 또는 체감 속도
- 최종 반복곡으로 확장했을 때의 예상 길이
- 장점과 주의점 한 줄
- 생성 도구 또는 제작 방식
- 외부 샘플 사용 여부와 라이선스

시안을 프로젝트의 `assets/audio/concepts/`에 저장하고 사용자에게 비교 재생 경로를 제공한다.  
사용자가 A·B·C 중 하나 또는 혼합 방향을 승인할 때까지 전체 제작으로 넘어가지 않는다.

### 3단계 · 승인된 인트로 음악 완성

승인된 방향으로 다음 파일을 제작한다.

| ID     | 파일명                            |      길이 | 사용 장면              | 조건                                   |
| ------ | --------------------------------- | --------: | ---------------------- | -------------------------------------- |
| BGM-01 | `bgm_title_forest_departure_loop` |   50~70초 | 표지·대기 화면         | 처음과 끝이 튀지 않는 완전한 무한 반복 |
| ST-01  | `st_title_start`                  | 1.5~2.5초 | 시작 버튼 후 화면 전환 | BGM의 주제 선율과 연결되는 짧은 출발음 |

인트로 BGM은 사용자가 버튼을 누른 뒤 재생되는 것을 전제로 한다. 브라우저 자동재생을 요구하지 않는다.

## 3. 파일 규격

### 마스터 파일

- BGM·스팅어: WAV, 48 kHz, 24-bit, stereo
- 짧은 효과음: WAV, 48 kHz, 24-bit. 공간감이 필요 없으면 mono 권장
- 클리핑 금지, 마스터 피크는 최대 -1 dBTP
- BGM은 약 -16 LUFS-I를 출발점으로 삼고 효과음보다 한 단계 뒤에 들리게 조정
- 짧은 효과음은 파일별 최대 음량만 같게 맞추지 말고 실제 체감 음량을 통일
- 무음 꼬리를 불필요하게 길게 두지 않음

### 웹용 파일

- `.ogg`와 `.mp3` 두 형식으로 함께 제공
- BGM MP3는 192 kbps 이상 권장
- 파일명은 소문자 영문, 숫자, 밑줄만 사용
- 루프 파일은 시작점과 끝점에서 클릭·호흡 끊김·리버브 단절이 없어야 함

### 저장 구조

```text
assets/audio/
├─ concepts/       # 승인 전 짧은 인트로 시안
├─ bgm/            # 반복 배경음악
├─ stingers/       # 장면 전환·등급 공개·결과 음악
├─ sfx/
│  ├─ ui/
│  ├─ preparation/
│  ├─ hero/
│  └─ battle/
├─ masters/        # WAV 원본
├─ audio-manifest.json
└─ audio-production-notes.md
```

## 4. 납품 기록

`audio-manifest.json`에는 각 파일별로 다음 정보를 기록한다.

```json
{
  "id": "HR-04",
  "file": "st_hero_common_reveal.ogg",
  "category": "hero",
  "durationMs": 2100,
  "loop": false,
  "volumeDefault": 0.8,
  "trigger": "hero_reveal_common",
  "source": "generated-or-original",
  "license": "project-use-cleared"
}
```

`audio-production-notes.md`에는 다음을 남긴다.

- 사용한 제작 도구와 버전
- 생성형 도구를 썼다면 최종 프롬프트
- 직접 녹음하거나 외부 샘플을 썼다면 원본 출처와 라이선스
- 편집·믹싱 방식
- 루프 지점과 페이드 권장값
- 아직 제작하지 않은 파일
- 앱 연결 시 주의할 점

라이선스가 불명확한 파일은 납품 목록에서 제외한다.

## 5. 검수 기준

### 분위기

- 표지 일러스트와 함께 재생했을 때 따뜻한 숲속 원정 분위기가 맞는가?
- 초등학생이 좋아할 만큼 선명하지만 지나치게 유아적이지 않은가?
- 교사가 수업 중 여러 번 들어도 피로하지 않은가?
- 최종 대전이 경쟁만이 아니라 세 팀의 공동 승리로 느껴지는가?

### 기술

- 모든 파일이 실제로 열리고 재생되는가?
- BGM 반복 지점에서 끊김이나 클릭이 없는가?
- 동일 계열 효과음의 체감 음량이 일정한가?
- 효과음 여러 개가 겹쳐도 날카롭거나 과도하게 크지 않은가?
- WAV, OGG, MP3의 길이와 시작 타이밍이 일치하는가?
- 파일명과 `audio-manifest.json`의 경로가 정확히 일치하는가?

### 접근성과 수업 환경

- 소리가 없어도 게임 결과와 정보가 화면에서 전달되어야 한다.
- 음소거와 효과음 크기 조절을 전제로 제작한다.
- 중요한 예고음은 화면 애니메이션과 함께 쓰며 소리만으로 정보를 전달하지 않는다.
- 놀라게 하는 갑작스러운 고음·굉음·큰 저음을 피한다.
