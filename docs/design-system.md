# 시작 화면 디자인 방향

## 2026-10-20 학생 공개 준비 · 최신 우선 기준

- 사용자는 초록덕후 스킬의 과도한 적용을 중단하도록 요청했다. 아래 과거 일반론의 비대칭·도장 그림자·종이 질감은 새로운 교사 화면에 적용하지 않는다.
- `frontend-design`은 원정 게임과 운영 도구의 시각적 역할을 분리하고, `ui-ux-pro-max`는 정보 위계·터치 간격·모바일 줄바꿈 검수에 사용한다. 초록덕후 스타일은 기존 숲색과 주아 제목의 맥락만 참고한다.
- 표지의 일러스트·로고는 유지한다. 원정 목록과 학생 화면의 상단에만 숲 일러스트를 쓰고 본문은 옅은 회색 배경과 흰 면으로 정리한다.
- 원정 목록은 가로 전체를 쓰는 간결한 행, 주 행동은 상단 `원정 만들기` 하나다. 모바일에서는 이름을 충분한 폭으로 먼저 보여 주고 시즌·열기는 아래 행에 둔다.
- 교사 화면은 장식용 번호 배지와 중첩된 큰 종이 상자를 없앤다. 순위·포인트는 원정대 명단 위에 놓아 먼저 보이게 한다.
- 학생 화면은 `우리 원정대 · 병력 카드 · 영웅 카드`로 제한한다. 실제 카드는 기존 카드 UI를 사용하되 아직 보유/구매가 아닌 둘러보기임을 알린다.
- 카드 한쪽 색 띠 금지, 명단 행 구분, 개인 배수 상세 표시라는 기존 사용자 결정은 유지한다.

## 2026-10-20 운영 화면 수정 기준 (최신 사용자 요청 우선)

- 표지의 숲속 모험 분위기와 주아 제목은 유지한다. 교사 운영 화면은 장식보다 정렬과 명단의 가독성을 우선한다.
- 카드 한 변에만 진한 색 띠를 넣지 않는다. 카드 전체에 같은 두께의 얇은 테두리를 사용하고 원정대 색은 제목·번호·테두리에만 절제해서 적용한다.
- 원정대 현황·명단은 같은 번호순 명단을 사용한다. 이름마다 작은 색상 칩을 만들거나 원정대장·도전점퍼 이름을 별도 구역에 반복하지 않는다.
- 원정대장은 이름 옆에 표시한다. 도전점퍼는 해당 명단 줄 전체 테두리와 짧은 `도전` 표시로 구별한다. 색만으로 의미를 전달하지 않는다.
- 개인 배수는 학생 상세에서만 조회·변경한다. 경기 기록판의 계산용 배수 표시는 유지한다.
- 명단 화면에서 원정대를 나란히 보여 준다. 각 원정대의 `대원 편성`에서 여러 학생을 한 번에 선택하며, 기존 소속과 이동 영향을 저장 전에 알린다.
- 기록 버튼의 불필요한 화살표, 도장형 그림자와 과도한 비대칭 곡률은 운영 화면에서 제거한다.
- 적용 스킬: `green-drawing-app-style`의 색상·글꼴 정체성, `ui-ux-pro-max`의 공통 접근성·44px 조작 영역·반응형·취소/복구 지침. 이번 편성 관련 로컬 검색에는 검증할 만한 정확한 항목이 없어 검색 결과는 적용하지 않았고 공통 지침으로 검수했다.

아래의 기존 스타일 일반론보다 이 최신 운영 화면 기준이 우선한다. 병력·영웅 카드의 독립 미리보기는 이번 변경 대상이 아니다.

## 디자인 기준 스킬

줄넘기 원정대의 UI를 제작하거나 수정할 때는 다음 순서로 디자인 기준을 적용한다.

1. `green-drawing-app-style`을 앱의 기본 시각 언어로 사용한다.
   - 크림 아이보리 `#FBFBF9`
   - 딥 포레스트 그린 `#1B4332`
   - 세이지 `#2D6A4F`
   - 민트 `#52B788`
   - 유기적인 비대칭 곡률, 잉크 도장형 그림자, 투명 배경 손그림 일러스트
2. `logo-design`은 앱 이름을 표시하는 워드마크와 재사용 가능한 브랜드 표시를 제작할 때 사용한다.
3. `ui-ux-pro-max`는 반응형 구조, 접근성, 터치 크기, 정보 위계와 상호작용 검수에 사용한다.
4. 이 문서와 마스터 명세에 적힌 줄넘기 원정대 고유 화면·캐릭터·용어는 위 스킬의 일반 권장안보다 우선한다.

두 스킬을 함께 사용할 때는 `green-drawing-app-style`이 미감과 브랜드를 결정하고,
`ui-ux-pro-max`가 사용성과 구현 품질을 검증한다. 스킬 예시에 등장하는 다른 앱의 문구·폴더 캐릭터·기능은
그대로 복사하지 않고 줄넘기 원정대의 숲속 모험 세계관에 맞게 바꾼다.

## 주제

세 팀의 8자 줄넘기 기록이 숲속 원정 경로로 합쳐지는 교실용 협력 게임이다. 교사 화면은
운영 도구답게 차분해야 하고, 학생 화면과 전자칠판은 다음 도전을 기대하게 해야 한다.

## 색

| 이름      | 값        | 역할                      |
| --------- | --------- | ------------------------- |
| 원정대 숲 | `#173E2C` | 제목, 주요 정보, 기준선   |
| 길잡이 잎 | `#3D7A55` | 진행 상태, 보조 강조      |
| 어린 잎   | `#8BBF93` | 배경 그래픽, 선택 상태    |
| 종이 지도 | `#FBFBF7` | 주 배경                   |
| 숲 안개   | `#E4EADF` | 구획, 비활성 정보         |
| 횃불      | `#E4A83A` | 주의, 중요한 한 번의 강조 |

팀 색은 초록·황금·파랑을 사용하되 이름과 번호를 항상 함께 표시한다.

## 글꼴

- 우선순위: `SUIT Variable`, `Pretendard Variable`, `Pretendard`, `Noto Sans KR`
- 앱 이름, 화면 제목, 게임 단계명처럼 짧고 중요한 제목에는 `Jua`를 사용한다.
- 입력값, 설명문, 표와 긴 본문은 가독성을 위해 `Pretendard` 또는 `SUIT`를 유지한다.
- 큰 제목은 원정대 깃발처럼 단단하게 표현하되 한글 글자가 서로 붙지 않도록 약간의 자간을 둔다.
- 본문은 80자 이내의 줄 길이와 1.7 이상의 줄 간격을 유지한다.

### 표지 제목 로고

- 표지의 `줄넘기 원정대`는 일반 제목 글꼴이 아니라 SVG 워드마크로 표시한다.
- 한글 글자 면은 OFL 라이선스의 `Jua`를 사용하고 앱에 글꼴 파일을 포함한다.
- 표지 두 줄 사이에는 글자 외곽선이 닿지 않을 정도의 여백을 유지한다.
- 영문 배너, 두 줄 한글 제목, 줄넘기는 동일한 중앙축에 정렬한다. SVG 텍스트는 중앙 앵커를 사용한다.
- 영문 배너는 한글 제목 외곽 너비의 약 90%, 손잡이를 포함한 줄넘기는 약 110%로 맞춘다. 영문 배너와 첫 줄 제목 사이에도 여백을 둔다.
- 짙은 숲색 외곽선, 금빛 안쪽 테두리, 제목 너비 안에서 짧은 U자를 이루는 줄넘기 줄과 양쪽 손잡이를 핵심 식별 요소로 사용한다.
- 데스크톱에서는 짙은 초록 글자 면, 모바일의 어두운 사진 위에서는 아이보리 글자 면으로 전환한다.
- 장식은 워드마크 안에서만 사용하며 본문·버튼 글꼴에는 적용하지 않는다.

## 레이아웃

```text
┌ 원정대 이름 ───────────────────────── 현재 단계 ┐
│                                                  │
│  핵심 문장과 상태 안내     ①──╲                 │
│                           ②─────── ? 비밀 보스   │
│                            ③──╱                  │
├──────────────────────────────────────────────────┤
│ 이번 단계의 결정          6개 결정 격자          │
└──────────────────────────────────────────────────┘
```

기본 정렬은 왼쪽이다. 세 팀의 경로가 오른쪽의 공동 목표로 모이는 그림을 시작 화면의 한 가지
기억점으로 사용한다. 동일한 둥근 카드의 반복은 피하고 선, 장부, 경로로 정보 관계를 드러낸다.

## 원칙

1. 학생에게는 경쟁보다 공동 원정이 먼저 보인다.
2. 교사에게는 현재 상태와 다음 행동이 먼저 보인다.
3. 장식은 숲, 줄, 경로를 설명할 때만 사용한다.
4. 팀은 색상만으로 구분하지 않는다.
5. 자동 모션은 한 화면에 한 번만 쓰며 모션 감소 설정을 존중한다.
