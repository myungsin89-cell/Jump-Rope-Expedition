# 줄넘기 원정대

2~4개 원정대의 8자 줄넘기 경기 기록을 팀 성장, 병력 준비, 비밀 보스와의 최종 대전,
영웅 수집으로 연결하는 교실용 협력·경쟁 게임이다.

## 시작하기

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

로컬 Supabase를 사용할 때는 Docker 실행 후 다음 명령을 사용한다.

```powershell
npm run supabase:start
```

로컬 실행 결과에 표시되는 API URL과 anon key를 `.env.local`에 입력한다. 실제 비밀 키는
저장소에 커밋하지 않는다.

## 검증 명령

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

## 현재 연결된 화면

> 2026-10-20 1차 개편 결과는 [운영 화면 구현 결과](./docs/operation-screen-implementation.md), 전체 목표와 남은 결정은 [운영 구조 정리와 개발 순서](./docs/operation-flow-reorganization.md)를 본다.

- 표지 → 원정 시작하기 → 기존 원정 목록 → 선택한 원정의 현황판. 새로 시작/이어가기 중간 창은 없다.
- 원정 만들기에서는 학생 명단만 필수이며 목록 표시 이름은 선택 사항이다. 기존 저장 이름과 학생 ID는 보존한다.
- 상위 메뉴는 `현황 · 명단 · 시즌 설정` 세 개다.
- 현황에서는 현재 기록 시즌·기간·경기 수와 원정대별 이름·대장·대원·도전점퍼·최근 순위·연습 획득 합계를 확인한다.
- 명단은 30명 기준 작은 행이며, 학생 추가·이름 수정·원정대 이름과 대장 지정은 모달로 처리한다. 편성과 도전점퍼·배수도 명단에서 관리한다.
- 기록 전 2~4개 원정대를 정할 수 있다. 작성·저장 기록이 있으면 미정인 수 변경 정책을 임의 적용하지 않고 기존 기록을 보호한다.
- 시즌은 기본 1개, 최대 5개이며 미래 시즌을 모두 설정할 필요는 없다.
- 현황의 `경기 기록하기`에서 바로 개수를 입력하고 연습 결과 저장 후 현황으로 돌아간다. 4위 포인트는 미정으로 표시한다.
- 명단의 `훈장 관리`에서 훈장을 만들고 학생 상세의 `받은 훈장`을 펼쳐 수여한다. 기본 제공 훈장은 없으며 이름·설명·아이콘/이미지를 직접 정한다.
- 수여당 소속 원정대에 연습 +10P를 한 번 반영하고, 현황 이름 옆 아이콘·학생 이력·서로 다른 수상자 진행도에 연결한다. 경기 저장은 훈장 포인트를 재지급하지 않는다.
- 연습 합계는 공식 잔액이 아니며 구매·보상에 쓰지 않는다. 공식 포인트·승점·영웅 추첨은 아직 연결하지 않았다.
- 학생용 화면에서는 자기 원정대 명단과 병력 4종·영웅 15종을 읽기 전용으로 둘러본다. 카드 도감은 실제 보유 카드가 아니며 보스·배치·개인 배수는 노출하지 않는다.
- 현황의 `학생 화면 공유`에서 같은 브라우저 미리보기가 가능하다. 다른 기기에 공유할 QR은 Supabase 게시 서버를 배포·설정한 뒤 사용할 수 있다.
- 게시 서버 소스는 포함되어 있으나 실제 프로젝트에는 아직 연결하지 않았다. 임시 교사 전용 게시 키를 사용하며 키 없는 수정은 허용하지 않는다.
- 교사 로그인·실제 시즌 시작·공식 포인트/보상 장부는 아직 연결하지 않았다. 교사 운영 원본과 연습 경기·훈장은 계속 로컬 브라우저에 저장된다.

직접 확인할 주소는 개발 서버 주소 뒤의 `/#/prepare`, `/#/preparations`다.

내일의 명단·팀 준비와 학생 읽기 전용 공개를 먼저 제공한다. 배포·서버 설정은 [첫 배포 안내](./docs/first-deployment-guide.md), 나머지 게임 구현은 [로컬 기능 구현 현황](./docs/local-feature-progress.md)을 따른다.

원정 내부 주소는 `/#/preparations/<ID>`(현황), `/roster`(명단), `/seasons`(시즌 설정)를 사용한다. 과거 저장 키와 원정 ID는 바꾸지 않는다.

제품의 확정 규칙은
[마스터 명세서](./줄넘기_원정대_개발_마스터_명세서_v1.0.md), 구현 결론은
[결정 로그](./docs/decision-log.md)를 기준으로 한다.
